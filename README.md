# GalleriaIDA

**GalleriaIDA** is an Android language-learning app for students. Players earn ⭐ stars by taking quizzes in their native language, then spend those stars to generate unique AI images that fill their personal gallery. Once they have a gallery, a suite of mini-games lets them revisit and play with their own images — turning the reward into a game.

## What the app does

1. A teacher or parent sets up the app once by entering a Gemini API key in **Settings**.
2. Each student creates a **player profile** with their name, native language, school class, and where they are in the school year.
3. Players take **quizzes** — questions generated by Gemini in the player's own language, calibrated to their school year.
4. Correct answers earn **stars**. Accumulate 100 ⭐ to create an AI-generated image.
5. When creating an image the player picks one word from three vocabulary groups (character, action, place). The app turns those words into an image via Pollinations or Gemini image generation.
6. The image and its bilingual metadata land in the player's **Gallery**.
7. Once a player has enough gallery images, **Mini-Games** unlock one by one, letting them play with their own pictures.

The entire player-facing UI is rendered in the player's chosen language via an on-the-fly translation layer — no separate resource files required.

## Star economy

| Action | Stars |
|---|---|
| Correct quiz answer | +3 ⭐ |
| All questions correct (perfect score bonus) | +10 ⭐ |
| One question wrong (near-perfect bonus) | +3 ⭐ |
| Create an image | −100 ⭐ |
| Play Puzzle | −10 ⭐ |
| Play Fill the Blank | −10 ⭐ |
| Play Memory Match | −10 ⭐ |
| Play One Piece | −5 ⭐ |
| Image Tournament | Free |

Stars are deducted the moment a paid mini-game starts and are **not refunded** if the player exits early.

## Quizzes & Gemini

Quizzes are generated at runtime by calling the **Gemini text model** configured in Settings. The prompt passes the player's language, school class, school-year position, and subject — Gemini returns a structured JSON array of questions.

Each question has a `level` (1–3), a `type` (`multiple_choice`, `true_false`, or `text`), and belongs to a `subject`/`category`. The question level doubles as a difficulty indicator; all correct answers currently award a flat 3 ⭐ regardless of level.

**History** — every submitted quiz is persisted locally (date, duration, score, all questions and answers) and viewable in the Quiz History screen.

**Error handling** — if Gemini returns a 429 (quota exceeded) the app surfaces a friendly "The server is busy" message. Missing API keys redirect the player to Settings.

### Gemini model selection

Settings exposes four separate model slots, each used for a distinct task:

| Slot | Purpose |
|---|---|
| **Questions** | Generates quiz questions |
| **Translation** | Translates the full `UiStrings` object into the player's language |
| **Image Prompt** | Builds the Pollinations/Gemini image prompt from the three chosen words |
| **Image Generation** | Gemini's image generation model (e.g. `imagen-3.0-generate-002`) |

Available models are fetched live from the Gemini API on the Settings screen.

## Image generation (Pollinations + Gemini)

When a player spends 100 ⭐ to create an image they choose:

- **🦸 Character** — a person, creature, or hero
- **⚡ Action** — what that character is doing
- **🗺️ Place** — where it happens

The app first calls the **Image Prompt** Gemini model to produce a rich English prompt from those three words. That prompt is then sent to the image back-end:

1. **Gemini image generation** (primary) — uses the configured `modelImageGeneration` slot.
2. **Pollinations** (fallback, tried in order) — three configurable model slots (`kontext` → `nova-canvas` → `flux` by default). A Pollinations API key is optional; without one the free public tier is used.

The resulting image is saved to local storage. The `GalleryItem` record stores both the English phrase/title and the player-language phrase/title, plus all three word choices in both languages.

Tapping a gallery image opens a full-screen viewer. Long-pressing the image shows a debug JSON sheet with all stored metadata (useful for teachers).

## Mini-games

All mini-games are reached from the **Mini Games** hub. Each game is locked until the player's gallery reaches a threshold:

| Game | Unlocks after | Cost |
|---|---|---|
| Puzzle | 1 image | 10 ⭐ |
| Fill the Blank | 6 images | 10 ⭐ |
| One Piece | 8 images | 5 ⭐ |
| Memory Match | 10 images | 10 ⭐ |
| Image Tournament | 16 images | Free |

### 🧩 Puzzle

A gallery image is sliced into a grid of tiles and shuffled. The player drags and swaps tiles to restore the original picture.

- **Easy** — 4 × 4 (16 tiles)
- **Medium** — 4 × 5 (20 tiles)
- **Hard** — 4 × 8 (32 tiles)

A "Show Image" button lets the player peek at the original. Completing the puzzle triggers a congratulation dialog. The player can re-roll to try a different gallery image.

### 🔡 Fill the Blank

The player is shown a blurred or masked gallery image. Below it are letter tiles. They must spell out the image's title letter by letter to "reveal" it.

- **Easy / Medium / Hard** — same words, different hint levels.
- Each round uses a different gallery image; the number of rounds scales with gallery size.
- Completing all rounds shows a summary with the score (how many titles were revealed correctly).

### 🔲 One Piece

A tiny, randomly cropped fragment of a gallery image is shown. The player picks which full image it came from out of multiple-choice options.

- **Easy / Medium / Hard** — the fragment gets smaller (harder) as difficulty increases.
- Costs 5 ⭐ (cheaper than other games).
- Multi-round format with a summary screen at the end.

### 🧠 Memory Match

Classic concentration / pairs game using the player's own gallery images.

- Each image appears twice (face down). Players flip cards two at a time; matching pairs stay face-up.
- **Easy** — small grid (fewer pairs)
- **Medium / Hard** — larger grids with more pairs
- A move counter and timer track performance. Completing all pairs shows a win dialog.

### 🏆 Image Tournament

A single-elimination bracket tournament where the player votes for their favourite image in head-to-head matchups.

- Requires 16 gallery images; bracket stages are R16 → QF → SF → Final.
- Each round shows two images side by side; the player taps **Pick ✨** to vote for the winner.
- The bracket advances until one image is crowned champion.
- Free to play — no star cost.

## Translation system

All player-facing strings live in a single Kotlin data class, `UiStrings`, with English defaults. When a player is selected the `AppViewModel` calls the **Translation** Gemini model once, passing the full list of English strings and asking for a JSON translation into the player's language. The result is parsed and cached locally (`UiStringsCache`) so subsequent launches don't need a network call.

**Cache mechanism (`UiStringsCache.kt`):** translations are stored as a `Map<String, String>` keyed by the same property names used in `UiStrings`. On cache hit, each property is populated from the map; missing keys fall back to the English default.

**Adding a new string:**
1. Add the property with an English default to `UiStrings.kt`.
2. Add the corresponding entry to both the constructor and the string-map in `UiStringsCache.kt`.
3. Use `uiStrings.<propertyName>` in the Composable.

Screens collect `viewModel.uiStrings` as a `StateFlow<UiStrings>` and read all displayed text from it. The Settings screen and admin dialogs are intentionally kept in hardcoded English.

## Setup instructions

### Prerequisites

- Android Studio Hedgehog or newer
- Android SDK 34+
- A [Google AI Studio](https://aistudio.google.com/) account to obtain a Gemini API key

### Build

```bash
git clone <repo-url>
cd GalleriaIDA
./gradlew assembleDebug
```

Install the resulting APK on a device or emulator running Android 9 (API 28) or higher.

### First-run configuration

1. Open the app and tap the **⚙️** settings icon (top-right of the player selection screen).
2. Enter your **Gemini API key** and tap **Test & Save**. The app will fetch available models.
3. Assign a model to each of the four task slots:
   - **Questions** — any text model (e.g. `gemini-2.0-flash`)
   - **Translation** — any text model
   - **Image Prompt** — any text model
   - **Image Generation** — an image-capable model (e.g. `imagen-3.0-generate-002`)
4. Optionally enter a **Pollinations API key** to access priority image generation. Leave blank to use the free public tier.
5. Tap the back arrow to return to player selection.

### Creating players

Tap **+ New Player** on the selection screen. Each player needs:

- A unique display name
- Their native language (used for quiz generation and UI translation)
- School class (e.g. "Class 3B")
- School-year position (Beginning / Middle / End — influences quiz difficulty)
